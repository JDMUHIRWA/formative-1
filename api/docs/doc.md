# Global Earthquake API Documentation (PostgreSQL + MongoDB)

## Overview

This API manages and analyzes earthquake data stored in either **PostgreSQL** or **MongoDB**.
It provides endpoints to **create, retrieve, update, and delete** earthquake records.
Both databases can be used independently, and the API ensures **data validation, reliability, and performance** for real-time analysis.

---

## Key Features

* **FastAPI-Powered**: High-performance API with automatic Swagger documentation.
* **Dual Database Support**: PostgreSQL (SQL) + MongoDB (NoSQL) integration.
* **Full CRUD Support**: Create, read, update, delete earthquake data.
* **Pydantic Validation**: Request/response schemas for data integrity.
* **Supabase & MongoDB Atlas Hosting**: Secure cloud-hosted databases.

---

## Database Schemas

### PostgreSQL `earthquakes` Table

| Column        | Type             | Description                               |
| ------------- | ---------------- | ----------------------------------------- |
| earthquake_id | SERIAL (PK)      | Unique ID for each earthquake record.     |
| location_id   | INTEGER          | Identifier for the earthquake’s location. |
| monitoring_id | INTEGER          | Identifier for monitoring data.           |
| tsunami_id    | INTEGER          | Identifier for tsunami data.              |
| magnitude     | DOUBLE PRECISION | Earthquake magnitude (Richter scale).     |
| depth         | DOUBLE PRECISION | Depth of the earthquake in kilometers.    |
| sig           | INTEGER          | Significance score.                       |
| Year          | INTEGER          | Year of occurrence.                       |
| Month         | INTEGER          | Month of occurrence.                      |

---

### MongoDB `earthquakes` Collection

Each document contains the following fields:

```json
{
  "_id": ObjectId,
  "location_id": 83,
  "monitoring_id": 81,
  "tsunami_id": 79,
  "magnitude": 8.1,
  "depth": 28.94,
  "sig": 1021,
  "Year": 2021,
  "Month": 3
}
```

> **Note:** `_id` is automatically generated by MongoDB. All other fields are required for the document.

## API Endpoints

### PostgreSQL

| Method | Endpoint            | Description                 |
| ------ | ------------------- | --------------------------- |
| POST   | `postgres/earthquakes`      | Create a record             |
| GET    | `postgres/earthquakes`      | Get all records (paginated) |
| GET    | `postgres/earthquakes/{id}` | Get one record by ID        |
| PUT    | `postgres/earthquakes/{id}` | Update a record             |
| DELETE | `postgres/earthquakes/{id}` | Delete a record             |

### MongoDB

| Method | Endpoint                  | Description               |
| ------ | ------------------------- | ------------------------- |
| POST   | `/mongo/earthquakes`      | Create a document         |
| GET    | `/mongo/earthquakes`      | Get all documents         |
| GET    | `/mongo/earthquakes/{id}` | Get one document by `_id` |
| PUT    | `/mongo/earthquakes/{id}` | Update a document         |
| DELETE | `/mongo/earthquakes/{id}` | Delete a document         |

## Troubleshooting

| Issue                       | Possible Cause                      | Fix                                               |
| --------------------------- | ----------------------------------- | ------------------------------------------------- |
| Internal Server Error (500) | Missing table/collection            | Create table (PostgreSQL) or collection (MongoDB) |
| Connection refused          | Incorrect URI/SSL                   | Check connection string & credentials             |
| Record not updating         | Wrong ID (`_id` or `earthquake_id`) | Use correct ID                                    |
| No data returned            | Empty table/collection              | Add records using POST endpoint                   |
